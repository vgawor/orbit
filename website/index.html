Questions

Do I need a MacBook with a notch?+

No. On screens without a notch, like an external display, Orbit floats as a glass pill just below the menu bar and works the same way.

Which macOS do I need?+

macOS 14 Sonoma or later. On macOS 26 you get Apple's Liquid Glass; on older versions, a frosted blur.

Why does macOS warn me the first time?+

Orbit isn't distributed through Apple's paid developer program, so macOS can't check it for you. Allow it once in System Settings → Privacy & Security → Open Anyway. Orbit is open source, so you can read the code or build it yourself instead. Company-managed Macs may need IT to allow it.

Does anything leave my Mac?+

Only what you connect yourself: Smart Ask and bots talk to Claude or ChatGPT, Tasks talks to HubSpot with your token, and Agents reads your GitHub reviews. With Pro, bot requests go through Orbit's server to the AI provider and aren't stored there. Everything else stays local.

Can bots do things without asking?+

Not unless you let them. Bots start by asking before every change. After you've approved the same kind of action a few times, Orbit offers to trust it, and even then you can undo it for 10 minutes. Bots only touch HubSpot deals you own.

What does Pro add if I have my own API key?+

Bots work with your own key for free. Pro adds the Pro add-ons and approvals on your phone, and bots can run on Orbit's keys so you don't need an API account or a second bill.

Can agents change my files on their own?+

No. Every edit and command needs your Allow in the notch. If you don't answer, it isn't allowed.

Which permissions does it ask for?+

Only the ones a feature needs, when you first use it: Calendar for meetings, Screen Recording for capture, Camera for the mirror and Microphone for mic safety.

Opening Orbit the first time

  1. Open the DMG and drag Orbit to Applications.
  2. Open Orbit. macOS says it can't check it for malware. Click Done.
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway.

You only do this once. Updates install by themselves after that.
