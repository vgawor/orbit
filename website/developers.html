Build for the notch.

Orbit is open source. Write a script add-on in any language in ten minutes, or build a full add-on in Swift. The best community add-ons are included in Pro, and their makers get paid.

Any language

Script add-ons

A folder with a widget.json and a script that prints JSON. Orbit runs it on an interval and shows a Home widget, a tab, a peek chip, and a nudge when you set attention. Shell, Python, Node, Go, anything.

  1. Make a folder in ~/Library/Application Support/Orbit/Widgets/
  2. Add widget.json and an executable script
  3. Settings → Add-ons → add it → Trust & run
Swift + SwiftUI

Swift add-ons

Full control of the notch panel, timers and macOS APIs. Conform to AddOnModule, use the glass design pieces, and open a pull request. Add-ons ship to everyone in the next release.

  1. Fork the repo, add a class in Viktor/Modules/AddOns/<Category>/
  2. Render it with --snapshot and add tests
  3. Open a pull request; we review within a week

An add-on in two files.

This one shows your battery in the peek and nudges you below 10 %. It ships with Orbit as an example, next to Hacker News (Python) and Git status.

# widget.json
{ "id": "battery", "name": "Battery",
  "category": "productivity", "run": "run.sh",
  "interval": 120, "symbol": "battery.75percent" }

# run.sh prints
{ "title": "Battery", "value": "84%",
  "subtitle": "discharging · 3:12 left",
  "progress": 0.84, "chip": "84%" }
