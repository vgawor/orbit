# The Orbit name and logo

The code is open, but the **Orbit** name, the Orbit character (the ringed planet with eyes) and
the app icon belong to Viktor Gawor. They tell people that a download is the real Orbit.

**You may:**
- say that your add-on works with Orbit, or that your fork is based on Orbit;
- use the name in articles, videos and reviews about Orbit;
- build and run Orbit from source for yourself, unchanged.

**Please don't:**
- publish a changed version of the app under the name Orbit or with the Orbit icon. Give your
  fork its own name and icon (in `Resources/Info.plist` and `Resources/AppIcon.icns`) and its own
  bundle id;
- use the name or character in a way that suggests we made or endorse something we didn't.

Not sure? Ask in a GitHub discussion or issue before you publish.
