# Security

Orbit can see your calendar, mail, files and screen, so we take security reports seriously.

**Please don't open a public issue for a security problem.** Use GitHub's private reporting
instead: the repository's **Security** tab → **Report a vulnerability**. Say what you found and how
to reproduce it. You'll get a reply within a few working days, and we'll tell
you when it's fixed and credit you if you'd like.

Only the latest release gets security fixes.
